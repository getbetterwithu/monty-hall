# 🚪 몬티홀 문제 확률 실험실 — TV 쇼 무대 에디션

중학교 2학년 '경우의 수와 확률' 단원을 위해 제작된 **수학교과서 연계 인터랙티브 시뮬레이터**입니다.

## 🌟 주요 특징 및 수업 활용 포인트

### 1. 📐 교과서식 수학적 분수($\frac{M}{N}$) 및 근삿값($\approx$) 엄밀 표기
- **성공 횟수 / 시행 횟수**: 교과서 정의대로 $\frac{\text{당첨 횟수}}{\text{전체 시행 횟수}}$ 분수 블록으로 시각화.
- **수학적 기호 자동 구분**:
  - 유한소수로 나누어떨어질 때: 등호 사용 (예: $\frac{13}{20} = 65.0\%$)
  - 순환소수로 반올림이 필요할 때: 근삿값 기호 사용 (예: $\frac{2}{3} \approx 66.7\%$)
- **"정확히 2배!" 배수 배지**: "바꿨을 때 당첨 확률이 유지했을 때의 정확히 2배!"임을 직관적으로 강조.
- **🔄 [데이터 초기화] 버튼**: 새 실험이나 다음 반 수업 시 누적 통계를 즉시 0회로 초기화.

### 2. ⚡ 초고속 무대 전략 실험 (슬롯머신 룰렛 애니메이션)
- 버튼을 누르면 화면의 문 3개가 촤라라락 열리고 닫히며 자동차🚗와 염소🐐가 폭풍처럼 쏟아져 나오는 고속 룰렛 연출 발동.
- 1.4초 동안 20회의 대결이 무대 위에서 빠르게 펼쳐지며 우측 분수와 꺾은선 그래프가 실시간으로 수렴.
  - ⚡ **['무조건 바꾸기' 20회 고수]**: 약 13~14승($\approx 66.7\%$) 시연
  - ⚡ **['무조건 유지하기' 20회 고수]**: 약 6~7승($\approx 33.3\%$) 시연
  - 🚀 **[50회 폭풍 슬롯머신]**: 대규모 표본의 대수의 법칙 시연

### 3. 🎭 무대 효과 및 도파민 밈 연출
- **사회자 '몬티'의 익살스러운 대사 말풍선**: 선택, 염소 개방, 밀당, 승패 상황별 코믹 리액션.
- **"Take the L (패배의 L을 가져가)" 밈 모션**:
  - 염소(꽝) 뽑았을 때: 붉은 사이렌 조명 + 몬티가 이마에 L 손가락을 얹고 촐싹촐싹 춤추는 애니메이션 발동! (`"넌 패배의 L이나 가져가라! 🤦‍♂️"`)
  - 자동차 당첨 시: 황금빛 스포트라이트 조명 + 폭죽(Confetti) + 양손 번쩍 W 세레머니!
- **순수 Web Audio API 신디사이저 사운드**: 외부 오디오 파일 다운로드 0%, 딸깍 소리, 서스펜스 럼블, 빵파레, 염소 울음소리 즉각 재생.
