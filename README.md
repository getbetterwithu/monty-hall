# 🚪 몬티홀 쇼! 바꿀까? 말까? — 실시간 투시 확률 실험실

중학교 수학 **'경우의 수와 확률'** 단원 수업을 위해 설계된 **전자칠판 · 2인 짝꿍 실시간 연동 몬티홀 시뮬레이터**입니다.

---

## 🌟 핵심 수업 구조 (듀얼 화면 실시간 연동)

하나의 방 코드(4자리 숫자 또는 QR 스캔)로 **도전자 무대 화면**과 **관전자 투시 화면**이 실시간 연결됩니다. 교실 전체 수업(`1:N`)과 모둠·짝꿍 활동(`1:1` 2인 모드)을 모두 지원합니다.

### 1. 📺 화면 1 — 도전자 무대 화면 (`도전자 무대 열기`)
- **대상**: 앞으로 나와 **전자칠판**에서 직접 고르는 학생, 또는 **2인 짝꿍 모드**에서 문을 선택하는 도전자.
- **정보 은닉(Blind Stage)**: 닫혀 있는 문 뒤의 정답(자동차·염소)이 화면과 DOM 모두에서 철저히 숨겨집니다.
- **진행 흐름**:
  1. 문 3개 중 1차 선택
  2. 사회자 몬티가 남은 문 중 염소 문 1개 개방
  3. **그대로 유지하기(`S`)** 또는 **남은 문으로 바꾸기(`R`)** 최종 결정 (문 직접 터치 또는 하단 대형 버튼)

### 2. 🔎 화면 2 — 관전자 X-Ray 투시 & 실시간 누적 화면 (`관전자 투시 화면`)
- **대상**: 자리에 앉아 태블릿·크롬북으로 지켜보는 **반 학생들**, 또는 **2인 짝꿍 모드**의 맞은편 검증관.
- **실시간 문 뒤 투시(X-Ray)**: 도전자가 고민하는 동안 1·2·3번 문 뒤에 **실제로 자동차가 있는지 염소가 있는지** 실시간으로 훤히 보입니다.
- **실시간 전략별 누적 비교**: 도전자가 **바꿨을 때**와 **유지했을 때** 각각 자동차인지 염소인지가 매 라운드 칩(`#1 🚗 자동차`, `#2 🐐 염소` 등)과 분수·백분율로 즉시 누적됩니다.
- **자율 현장 응원**: 화면 내 힌트·투표 버튼을 두지 않아, 교실 현장에서 아이들이 육성으로 자유롭게 심리전과 응원을 펼칠 수 있습니다.

### 3. 🎯 20회 제한 & 목표 챌린지 (`66.6%` 돌파 미션)
- 기본 **20회 시행 제한**으로 긴장감 있게 진행됩니다.
- 20회 완료 시 전체 자동차 당첨률이 **`66.6%` 초과**(20번 중 **14번 이상** 당첨 = `70.0%`)이면 **20회 챌린지 미션 달성 인증서**가 발급됩니다.

### 4. ⚡ 1인 실험실 & 초고속 무대 검증 (`1인 실험 & 초고속 검증`)
- 혼자 연습하거나 수업 마무리 정리 시 **'무조건 바꾸기 20회'** vs **'무조건 유지하기 20회'** 버튼을 누르면, 무대 위 문이 실제로 선택·염소 개방·변경/유지·전체 공개 과정을 고속으로 수행하며 **큰 수의 법칙 수렴 그래프**를 실시간으로 그립니다.

## 📐 수학교과서 연계 디테일 & 연출

- **정통 세로 분수 및 등호·근삿값 자동 판별**:
  - $\frac{\text{성공 횟수}}{\text{시행 횟수}}$ 세로 분수 표기
  - 유한소수로 나누어떨어질 때는 등호(`=`, 예: `14 / 20 = 70.0%`), 순환소수 반올림일 때는 근삿값 기호(`≈`, 예: `2 / 3 ≈ 66.7%`) 자동 적용
- **커스텀 벡터(SVG) 일러스트 & 리액션**:
  - 평면 이모지 대신 직접 제작한 슈퍼카, 풀 씹는 염소, 쇼호스트 몬티 캐릭터 적용
  - **염소(꽝) 선택 시**: 사회자 몬티가 이마에 **L**을 얹고 흔드는 **"Take the L (패배의 L을 가져가)"** 댄스 애니메이션 발동
  - **자동차 당첨 시**: 선글라스 **Victory W** 점프 + 폭죽(Confetti) + 팡파레 사운드(Web Audio API 자체 합성)
- **교사용 히든 설정 (학생 비노출)**:
  - 학생 화면에는 설정 버튼이 보이지 않으며, 좌측 상단 **`🚪 몬티홀 쇼!` 로고를 5회 연속 클릭**할 때만 교사용 설정 모달(시행 횟수, 챌린지 목표 커트라인 `%`, 선택적 Firebase URL, 교사용 관전자 화면 새 창 열기)이 열립니다.

## ⌨️ 키보드 단축키 (전자칠판 · 교사 PC)
- `1`, `2`, `3`: 문 선택 (2단계에서는 해당 문으로 유지/바꾸기 즉시 결정)
- `R` (또는 `ㄱ`): 남은 문으로 바꾸기 (Switch)
- `S` (또는 `ㄴ`): 처음 문 그대로 유지하기 (Stay)
- `Space`: 결과 확인 후 다음 라운드 진행
